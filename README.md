# Drumod4 Drums VST

Official distribution repository for **Drumod4 Drums VST** by **Force56 Audio Software**.

Drumod4 is a drum machine plugin based on the classic **Alesis D4**, bringing its complete original sound set into a modern, straightforward software instrument.

It includes all **500 original drum and percussion sounds**, with **12 pads**, individual pad volume, panning and tuning controls, plus **21 factory drumset presets** faithfully recreated from the original hardware.

Drumod4 is designed as a **no-frills, plug-and-play drum machine**: load it in your DAW, pick a drumset, and start making music.

## Formats

* **Windows:** VST3 and Standalone
* **macOS:** VST3, Audio Unit (AU) and Standalone
